LAPORAN PROYEK WEBSITE
Ale's Place Cipoho - Website Reservasi Restoran

Tanggal: 14 Maret 2026

1. Latar Belakang
Proyek ini dikembangkan untuk menyediakan website profil dan reservasi untuk restoran Ale's Place Cipoho. Website dirancang agar pengunjung dapat melihat informasi restoran, menelusuri menu, melakukan reservasi meja, dan menghubungi restoran melalui satu platform yang sederhana, cepat, dan mudah digunakan.

2. Tujuan Pengembangan
1) Menyediakan media informasi restoran secara online.
2) Menampilkan katalog menu dengan fitur pencarian dan filter.
3) Menyediakan form reservasi meja dengan validasi input.
4) Menyediakan informasi kontak, jam operasional, dan media sosial.
5) Menyusun fondasi agar proyek dapat dikembangkan ke versi WordPress.

3. Ruang Lingkup Sistem
Website mencakup dua bagian implementasi:
1) Website statis (HTML, CSS, JavaScript) dengan 4 halaman utama.
2) Tema WordPress kustom dengan struktur template dan dukungan manajemen menu.

4. Teknologi yang Digunakan
1) HTML5 untuk struktur halaman.
2) CSS3 untuk desain visual dan responsivitas.
3) JavaScript murni untuk interaksi (tanpa framework).
4) WordPress Theme Development (PHP) untuk versi CMS.

5. Struktur Halaman dan Fitur Utama
A. Beranda (index.html)
- Hero section dengan identitas restoran dan ajakan melihat menu.
- Shortcut card untuk akses cepat ke Menu, Reservasi, dan Kontak.
- Bagian profil singkat dan statistik restoran (varian menu, pelanggan, rating).

B. Menu (menu.html)
- Daftar menu dalam bentuk card (gambar, nama, harga, deskripsi).
- Filter kategori: ramen, appetizer, dessert, drink.
- Tab filter tambahan: semua, populer, terbaru, promo.
- Fitur pencarian menu berdasarkan nama atau deskripsi.

C. Reservasi (reservasi.html)
- Form reservasi berisi nama, telepon, tanggal, waktu, jumlah orang, dan catatan.
- Validasi field wajib dan format nomor telepon.
- Batas tanggal reservasi minimal hari ini.
- Pesan sukses setelah submit dan ringkasan data reservasi.

D. Kontak (kontak.html)
- Informasi alamat, telepon, email, dan WhatsApp.
- Jam buka untuk hari kerja, akhir pekan, dan catatan hari libur.
- Tautan media sosial.

6. Desain Antarmuka
1) Menggunakan palet warna hangat bertema restoran (krem, cokelat kemerahan, aksen emas).
2) Gaya tipografi menggabungkan serif untuk judul dan sans-serif untuk isi.
3) Tata letak responsif untuk desktop, laptop, tablet, dan mobile.
4) Navigasi konsisten di semua halaman dengan header dan footer seragam.

7. Implementasi JavaScript
Fitur JavaScript utama meliputi:
1) Filter dan pencarian menu secara real-time.
2) Highlight menu navigasi aktif sesuai halaman.
3) Validasi form reservasi sebelum submit.
4) Tampilkan notifikasi sukses dan reset form setelah submit.
5) Smooth scrolling untuk tautan anchor.

8. Implementasi Tema WordPress
Versi WordPress disiapkan pada folder wp-theme/ales-place-cipoho dengan komponen:
1) Template halaman: home, menu, reservasi, kontak, dan page umum.
2) Custom Post Type: menu_item.
3) Custom Taxonomy: menu_category.
4) Meta box admin untuk harga, deskripsi singkat, dan status ketersediaan menu.
5) Fungsi helper untuk format harga dan pengambilan data menu.

Dengan struktur ini, admin dapat mengelola item menu melalui dashboard WordPress tanpa mengubah kode manual.

9. Arsitektur Sistem (Ringkas)
Pola yang diterapkan adalah Modular Monolith sederhana:
1) Lapisan presentasi: HTML/CSS untuk tampilan.
2) Lapisan logika klien: JavaScript untuk interaksi UI.
3) Lapisan konten (versi WordPress): PHP + data WordPress untuk manajemen konten.

Alasan pemilihan:
- Cocok untuk skala proyek kecil-menengah.
- Implementasi cepat dan mudah dipelihara.
- Biaya pengembangan lebih rendah dibanding arsitektur terdistribusi.

Trade-off:
- Belum ideal untuk beban sangat besar.
- Fitur reservasi masih simulasi dan belum tersambung ke backend database khusus.

10. Hasil Pengujian Fungsional
Pengujian utama yang telah dilakukan:
1) Navigasi antar halaman berjalan normal.
2) Filter kategori dan tab menu bekerja sesuai data atribut.
3) Pencarian menu menampilkan hasil yang relevan.
4) Form reservasi menolak input tidak valid dan menerima input valid.
5) Tampilan responsif berjalan di berbagai ukuran layar.

11. Kelebihan dan Keterbatasan
Kelebihan:
1) Antarmuka bersih, konsisten, dan mudah dipahami.
2) Fitur inti restoran sudah tersedia end-to-end di sisi frontend.
3) Sudah disiapkan jalur migrasi ke WordPress untuk kebutuhan admin konten.

Keterbatasan saat ini:
1) Submit reservasi masih simulasi (belum terhubung API/database).
2) Beberapa aset gambar masih placeholder.
3) Belum ada autentikasi admin khusus di luar dashboard WordPress.

12. Rencana Pengembangan Lanjutan
1) Integrasi backend untuk penyimpanan data reservasi.
2) Integrasi notifikasi email/WhatsApp otomatis.
3) Integrasi pembayaran online untuk booking tertentu.
4) Penambahan dashboard laporan reservasi harian/mingguan.
5) Optimasi SEO dan performa produksi.

13. Kesimpulan
Website Ale's Place Cipoho berhasil memenuhi kebutuhan dasar digital restoran, yaitu menampilkan profil usaha, katalog menu interaktif, form reservasi, dan informasi kontak. Implementasi statis sudah berfungsi baik untuk kebutuhan presentasi dan validasi frontend, serta telah dilengkapi fondasi tema WordPress agar pengelolaan konten lebih fleksibel. Secara keseluruhan, proyek siap digunakan sebagai baseline dan dapat dilanjutkan ke tahap integrasi backend untuk operasional penuh.
