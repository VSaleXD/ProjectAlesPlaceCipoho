# Assets - Icons

Folder ini berisi semua SVG icons yang digunakan di website.

## Catatan
Saat ini, icon SVG sudah di-embed langsung di dalam file HTML untuk kemudahan.
Jika ingin memisahkan icon menjadi file terpisah, simpan di folder ini.

## Format
- Semua icon menggunakan format SVG
- Ukuran standar: 24x24px atau 32x32px
- Warna: dapat disesuaikan dengan CSS `currentColor`

## Icon yang Digunakan
- User icon (untuk "Tentang Kami")
- Book icon (untuk "Lihat Menu")
- Calendar icon (untuk "Reservasi Meja")
- Chat icon (untuk "Hubungi Kami")
- Location icon (untuk alamat)
- Phone icon (untuk telepon)
- Email icon (untuk email)
