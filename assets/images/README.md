## Catatan
- Semua gambar menggunakan format JPG atau PNG
- Ukuran file disarankan tidak lebih dari 200KB per gambar untuk performa optimal
- Gambar harus memiliki resolusi yang baik untuk tampilan di layar laptop (≥1366px)
- Pastikan gambar memiliki pencahayaan yang baik dan menampilkan makanan secara menarik
